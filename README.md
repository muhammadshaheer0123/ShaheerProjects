# ShaheerProjects

A collection of projects. Each project lives in its own folder.

| Project | Stack | Deploy |
| --- | --- | --- |
| [muhammad-shaheer-portfolio](./muhammad-shaheer-portfolio) | React 19, Vite, Three.js, React Three Fiber | Vercel |

## Deploying a project to Vercel

Projects live in subfolders, so set the **Root Directory** in Vercel
(Project Settings > General) to the project's folder, e.g. `muhammad-shaheer-portfolio`.
Each project has its own `vercel.json`; Vercel then builds and deploys on every push to `main`.

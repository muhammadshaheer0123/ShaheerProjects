# Stratum — Civil & Structural Engineers

Single-page landing site. Static HTML/CSS/JS — no build step.

- `assets/js/bridge.js` — Three.js cable-stayed bridge (steel truss deck) that assembles on scroll
- `assets/js/terrain.js` — contour-terrain shader for the Method section
- `assets/js/drawings.js` — SVG project elevations
- `assets/js/main.js` — GSAP ScrollTrigger + Lenis wiring, nav, form

Run locally (ES modules need a server):

```bash
python3 -m http.server 5173
```
